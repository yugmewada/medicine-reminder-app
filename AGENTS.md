# AGENTS.md

Instructions for AI coding agents working in this repository.

**Read [docs/MASTER_PROMPT.md](docs/MASTER_PROMPT.md) first. It is the single source of truth.** It covers product boundaries, toolchain, architecture (auto_route, Riverpod MVI, Freezed), localization, design tokens, common widgets, utilities in `lib/core/utils/`, the UX spec and the tests. Do not duplicate its rules here; update that file when a decision changes.

The skills in `.claude/skills/*/SKILL.md` are mandatory reading for relevant work. §11 of the master prompt maps each skill to this repo. Where a skill differs from the master prompt, the master prompt wins.
